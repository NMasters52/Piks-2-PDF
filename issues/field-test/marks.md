# What would photo markings cost?

Label: wayfinder:prototype

Parent: [Field-test walk improvements](map.md)

## Question

Can editable strokes stay aligned through scaling and export, and how much storage and PDF size do representative drawings add? Baseline experiment with pdf-lib on ten field PDFs: a line and ellipse on each of 59 pages added 15,733 bytes total against the same PDFs re-saved without marks. Touch input, per-photo positioning, editable stroke storage and freehand drawings still need evaluation.
